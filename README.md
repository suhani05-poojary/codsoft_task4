# 🎮 Rock Paper Scissors Game

## 📌 Description
This is a Python-based Rock-Paper-Scissors game where the user plays against the computer.  
The computer randomly selects a choice, and the winner is determined using standard rules:

- Rock beats Scissors  
- Scissors beats Paper  
- Paper beats Rock  

The game also tracks scores across multiple rounds and allows the user to play again or exit.

---

## 🛠️ Features
- User input (rock / paper / scissors)
- Random computer selection
- Winner determination logic
- Score tracking
- Multiple rounds
- Input validation
